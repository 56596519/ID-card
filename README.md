# 身份证拼版助手（IDCard A4 Layout）

任意角度拍摄身份证正反面，自动识别四角、透视拉正、方向校正，拼版到一张标准 A4 页面，可直接打印或导出图片。**纯本地离线运行，照片不离开本机。**

面向打印店、企事业单位复印归档场景：手机随手拍，无需摆正、无需裁剪，即拍即拼即打印。

---

## 一、功能特性

- **自动拉正**：基于深度学习检测证件四角，无论上传时是横拍、竖拍还是倾斜拍摄，都能透视校正为正面矩形。
- **方向自动校正**：自动判断 0° / 90° / 180° / 270°，倒置、横置照片均可转正。
- **真实圆角**：按真实证件圆角（3 mm 圆角）拼版，边缘自然。
- **标准 A4 拼版**：人像面在上、国徽面在下，按 300 dpi（2480 × 3508）输出，居中排版，打印不偏位、不产生第二页。
- **画面调节**：亮度、锐化滑块，仅作用于 A4 拼版框内图片，不影响其他区域。
- **一键打印 / 下载 PNG / 重置（下一位）**。
- **右键复制**：支持"复制图像""复制 A4 拼版图片"，可直接粘贴到 QQ / 微信 / Word。
- **隐私安全**：所有 AI 推理与图像处理在本机浏览器完成，无后端、无上传、无联网。

## 二、技术原理

| 环节 | 方案 |
|---|---|
| 证件四角检测 | DocAligner 神经网络（lcnet100 + bifpn 四角热力图，含缺角几何补全） |
| 透视拉正 | 根据四角点做透视变换（warp），得到正面矩形 |
| 方向分类 | PP-LCNet / DocOri 模型，输出 0/90/180/270 并旋转 |
| 推理运行时 | onnxruntime-web（WebAssembly + SIMD），单线程，完全离线 |
| 拼版输出 | Canvas 绘制，300 dpi A4，圆角裁剪，居中排版 |

模型与 WASM 引擎以 base64 内联于本地脚本，保证 `file://` 双击打开即可用；首次上传照片时才懒加载引擎，页面打开即用。

## 四、使用方式

### 1. 网页版（免安装）
双击 `index.html`，用 Chrome / Edge 打开 → 上传身份证人像面、国徽面 → 自动拼版 → 打印或下载。

### 2. 桌面版（安装）
运行 `dist/身份证拼版助手-Setup-2.0.0.exe`，按向导安装（默认仅为当前用户，免 UAC），开始菜单 / 桌面启动。
- 点击窗口右上角 X：程序隐藏到右下角系统托盘后台常驻；
- 单击托盘图标恢复窗口；右键托盘图标可退出。

## 五、开发与打包

```bash
# 安装依赖
npm install

# 开发运行
npm start

# 引擎自检（验证 WASM / 模型加载）
npm run selftest

# 打包桌面安装程序（NSIS，输出至 dist/）
npm run dist
```

## 六、系统要求

- **桌面安装版**：Windows 7 / 8 / 8.1 / 10 / 11（基于 Electron 22，Win7 兼容的最后版本）。
- **网页版**：支持 WASM SIMD 的现代浏览器，推荐 Chrome / Edge（Win7 上需 Chrome / Edge 109 最后版本）。
- AI 推理使用本机 CPU，无需独立显卡、无需服务器。

## 七、技术栈与许可

- 前端：原生 HTML / CSS / JavaScript（无框架、无构建）
- 推理：onnxruntime-web（MIT）
- 模型：DocAligner、PP-LCNet / DocOri（Apache-2.0）
- 桌面封装：Electron + electron-builder（NSIS）

> 本程序为内部工具，纯本地离线运行，不收集任何照片或个人信息。
